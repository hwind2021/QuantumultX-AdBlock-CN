# 01 · 快速上手：10 分钟配好

本文带你从零完成配置。假定你已经安装并可以正常打开 Quantumult X（下称「圈 X」）。

---

## 先搞清楚：你要配的是哪三样东西

圈 X 去广告靠的是三种机制，它们**互相独立、按需启用**：

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│   ① 分流规则 (filter)    ← 最基础，不需要 MITM，必装     │
│      在连接层直接拒绝广告域名                            │
│                                                         │
│   ② 重写规则 (rewrite)   ← 需要 MITM，精准度高           │
│      解密 HTTPS 后按 URL 匹配，返回空广告                │
│                                                         │
│   ③ JS 脚本 (script)     ← 需要 MITM，体验最好           │
│      改写响应 JSON，让 App 瞬间跳过而非干等超时          │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**如果只想去掉大部分开屏广告，只装 ① 就够了。**
想做到「开屏一闪而过、几乎无感知」，①②③ 全上。

---

## 方案 A：只装分流规则（5 分钟，无需 MITM）

### 步骤 1 · 订阅开屏广告专项

1. 打开圈 X，点右下角**风车图标**
2. 进入「**配置文件**」
3. 点右上角 **`+`** → 选择「**远程资源**」
4. 填入名称 `Splash-Killer`，类型选「**分流规则**」
5. URL 填入：

```
https://raw.githubusercontent.com/hwind2021/QuantumultX-AdBlock-CN/main/quantumultx/filter/Splash-Killer.list
```

6. 右上角「**保存**」，等待下载完成

### 步骤 2 · 订阅 HTTPDNS 拦截

**这一步很多人会漏，但它决定了前一步的效果上限。**

同样方式添加，名称 `BlockHttpDNS`，类型「分流规则」：

```
https://raw.githubusercontent.com/hwind2021/QuantumultX-AdBlock-CN/main/quantumultx/filter/BlockHttpDNS.list
```

> **为什么必须装？** 头条系、阿里系、腾讯系 App 会绕过系统 DNS，
> 直接向 HTTPDNS 服务器查询广告域名的真实 IP。你本地拦了域名，
> 它照样能通过 IP 连上广告服务器。这一层不堵住，拦截率会掉一大截。

### 步骤 3 · 订阅通用广告规则（推荐）

名称 `AdBlock-Lite`，类型「分流规则」：

```
https://raw.githubusercontent.com/hwind2021/QuantumultX-AdBlock-CN/main/quantumultx/filter/AdBlock-Lite.list
```

这条覆盖的是 App 内的信息流广告、banner、弹窗，不只是开屏。

### 步骤 4 · 启用分流

回到圈 X 首页 → 底部「**分流**」→ 确认刚添加的三条规则都处于**开启**状态
（开关为绿色）。

### ✅ 验证是否生效

打开任意带开屏广告的 App（比如微博、知乎、抖音），观察：

- **生效**：开屏直接跳过，或只剩一两秒的纯色启动页
- **未生效**：广告完整展示

如果没生效，先看 [07-常见问题排查](07-常见问题排查.md)。

## 方案 B：分流 + 重写 + 脚本（15 分钟，效果最佳）

在方案 A 基础上继续。

### 步骤 5 · 开启 MITM 并安装证书

1. 圈 X → 「**设置**」→「**MITM**」
2. 打开「**启用 MITM**」开关
3. 点击「**生成证书**」→ 按提示安装并信任描述文件
4. 详细步骤见 [06-MITM与证书配置](06-MITM与证书配置.md)

> MITM 是全流量的 HTTPS 解密。**只对你列进 `hostname` 的域名生效**，
> 其余流量不受影响，不必担心。

### 步骤 6 · 配置 MITM 主机名

在 MITM 设置的「**hostname**」区域，加入本项目提供的清单。

清单地址：[`quantumultx/mitm/MITM.list`](../quantumultx/mitm/MITM.list)

由于圈 X 的 hostname 需要单行逗号分隔，推荐这么操作：

1. 在电脑/手机浏览器打开上面的 `MITM.list`
2. 复制全部主机名（去掉 `#` 开头的注释行）
3. 粘贴到圈 X 的 hostname 输入框

> 圈 X 的 hostname 支持 `%APPEND%` 语法追加到系统默认值后面，
> 建议保留默认内容，用 `%APPEND%, 你的域名1, 域名2...` 的形式。

### 步骤 7 · 订阅重写规则

回到「配置文件」→ `+` → 「远程资源」，类型选「**重写规则**」：

名称 `AdBlock-Splash`：
```
https://raw.githubusercontent.com/hwind2021/QuantumultX-AdBlock-CN/main/quantumultx/rewrite/AdBlock-Splash.conf
```

名称 `AdBlock-Feed`（可选，管信息流广告）：
```
https://raw.githubusercontent.com/hwind2021/QuantumultX-AdBlock-CN/main/quantumultx/rewrite/AdBlock-Feed.conf
```

### 步骤 8 · 安装 JS 脚本

1. 打开 [`splash-killer.js`](../quantumultx/script/splash-killer.js)
2. 全选复制内容
3. 圈 X → 「**脚本**」→ 右上角 `+` → 「**新建脚本**」
4. 名称填 `splash-killer`，粘贴内容，保存
5. 同样方式安装 [`feed-killer.js`](../quantumultx/script/feed-killer.js)

### 步骤 9 · 让重写规则用上你的脚本

本项目提供的 `AdBlock-Script.conf` 里，脚本路径默认指向本仓库的 raw 地址。
如果你想用本地脚本，需要把规则里的 URL 改成圈 X 的本地格式。

圈 X 本地脚本引用格式：
```
^https?:\/\/app\.bilibili\.com\/x\/v2\/splash\/list url script-response-body splash-killer.js
```

即：把 `https://.../xxx.js` 换成 `脚本名.js`。

## 推荐配置组合

| 你的情况 | 建议组合 |
|---|---|
| 只想去掉开屏广告，不想折腾 | `Splash-Killer` + `BlockHttpDNS` |
| 想要干净完整的体验 | `Splash-Killer` + `BlockHttpDNS` + `AdBlock-Lite` + `AdBlock-Splash`(MITM) |
| 追求极致，不在乎耗电 | 全部规则 + `AdBlock-Full` + 脚本 |
| 设备较老 / 在意续航 | 只用 `Splash-Killer` + `BlockHttpDNS`，别开 MITM |

## 常见问题速查

**Q：装完之后 App 打不开了？**
→ 立刻在「分流」里关掉刚加的规则，确认是哪个导致的，然后到
[07-常见问题排查](07-常见问题排查.md) 查看处理方式，并欢迎提 Issue。

**Q：为什么有的广告还在？**
→ 三种可能：① 该 App 用了未覆盖的广告 SDK；② 广告走 HTTPDNS 未被拦截；
③ 广告素材在 App 内已预缓存。详见 [02-开屏广告原理](02-开屏广告原理与拦截策略.md)。

**Q：MITM 会不会让我的密码泄露？**
→ 不会。MITM 在你本机解密，数据不经过第三方。但**只信任你自己生成的证书**，
绝对不要安装来源不明的证书描述文件。
