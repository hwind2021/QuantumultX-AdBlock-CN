## 二、国内访问 GitHub raw 很慢怎么办

`raw.githubusercontent.com` 在国内部分地区访问不稳定。以下是替代方案，
**任选其一即可**。

### 方案 1：jsDelivr CDN（推荐，无需改动习惯）

把域名部分替换：

```
https://raw.githubusercontent.com/hwind2021/QuantumultX-AdBlock-CN/main/...
                    ↓ 替换为
https://cdn.jsdelivr.net/gh/hwind2021/QuantumultX-AdBlock-CN@main/...
```

例如：

```
https://cdn.jsdelivr.net/gh/hwind2021/QuantumultX-AdBlock-CN@main/quantumultx/filter/Splash-Killer.list
```

> 注意：jsDelivr 有缓存，更新可能延迟数小时。

### 方案 2：GitHub Proxy 加速

```
https://ghproxy.com/https://raw.githubusercontent.com/...
```

或

```
https://ghproxy.net/https://raw.githubusercontent.com/...
```

> 第三方代理有隐私风险，请自行判断。

### 方案 3：Fork 到 Gitee（国内速度最快）

1. 在 Gitee 导入本仓库（支持从 GitHub 一键导入）
2. 使用 Gitee 的 raw 地址

> Gitee 的自动同步需要手动触发，或使用其镜像功能。

### 方案 4：自托管

见 [09-自托管与二次开发](09-自托管与二次开发.md)。

## 三、每日更新机制

### 更新时序

```
每日 04:00 (UTC+8)
    │
    ├─ ① 拉取 8 个上游源（并发）
    │
    ├─ ② 归一化 → 白名单过滤 → 去重压缩
    │
    ├─ ③ 生成全部产物
    │
    ├─ ④ 运行安全校验 (verify.py)
    │      ├─ 通过 → 继续
    │      └─ 失败 → 中止，保留上一版，推送告警
    │
    ├─ ⑤ 生成 CHANGELOG 与统计
    │
    └─ ⑥ 自动提交并推送
```

### 为什么是 04:00

- 避开上游项目的构建高峰
- 国内凌晨网络状况好
- 用户起床时已完成更新

### 校验失败会怎样

**不会用有问题的规则覆盖线上版本。**

校验器会检查：

1. 是否误杀关键业务域名（支付 / 登录 / 系统服务）
2. 规则语法是否合法
3. 规则量是否在合理区间（异常说明上游数据出问题）
4. 是否存在冗余规则

任一项**错误级别**失败即中止提交，保留上一版可用规则，
并在仓库 Actions 页面显示失败状态。

## 四、手动触发更新

不想等凌晨？可以手动触发：

1. 打开仓库页面
2. 点击「**Actions**」标签
3. 左侧选择「**每日规则更新**」
4. 右侧「**Run workflow**」→ 选择分支 → 点击运行

约 3~5 分钟后完成。

## 五、圈 X 侧的自动更新

圈 X 的远程资源会**自动重新拉取**（默认约每 12 小时，
或在圈 X 启动时、手动下拉刷新时）。

### 手动刷新

```
圈 X → 配置文件 → 找到对应规则 → 长按 → 更新
```

或下拉列表触发全部更新。

### 确认更新是否生效

打开规则文件，查看头部：

```
# UPDATED: 2026-09-04 18:54:55 (UTC+8)
```

这个时间戳是构建时间，可以据此判断你用的是不是最新版。

## 六、使用定时任务自动更新脚本

圈 X 的「定时任务」可以定期重新下载脚本，适合使用远程脚本的场景。

本项目提供了示例：[`quantumultx/task/task.conf`](../quantumultx/task/task.conf)

配置方法：

1. 圈 X → 配置文件 → `+` → 添加 `task.conf`
2. 或把内容合并进你的主配置文件

```ini
[task_local]
0 5 * * * https://raw.githubusercontent.com/.../splash-killer.js, tag=开屏去广告脚本, img-url=..., enabled=true
```

格式说明：

```
分 时 日 月 周   脚本URL, tag=名称, enabled=true
```
